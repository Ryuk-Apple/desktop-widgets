# Desktop-Widgets

Glas-Widgets für den Windows-Desktop: **System** (Prozessor, Arbeitsspeicher, Grafikkarte, Festplatten), **Notizen** (To-do und Zettel) und **Tagesmenü** (jeden Tag ein Thema mit Vorspeise, Hauptgang und Nachspeise von Chefkoch, mit Zutaten, Zubereitung und Einkaufsliste).

## Herunterladen

**[Neueste Version herunterladen](https://github.com/Ryuk-Apple/desktop-widgets/releases/latest)** – dort unter „Assets“ auf `Desktop-Widgets.zip` klicken.

1. ZIP entpacken (Rechtsklick → „Alle extrahieren“) und den Ordner an einen festen Platz legen, z. B. in „Dokumente“.
2. `Desktop-Widgets.exe` starten. Meldet Windows „Der Computer wurde durch Windows geschützt“: „Weitere Informationen“ → „Trotzdem ausführen“ (die App ist nicht signiert).
3. Rechtsklick auf ein Widget öffnet das Menü, z. B. für „Mit Windows starten“.

Alles Weitere steht in der Datei „Lies mich.txt“ in der ZIP.

## Updates

Die App meldet neue Versionen selbst: Im obersten Widget erscheint „Update verfügbar“, ein Klick auf „Installieren“ genügt. Ein GitHub-Konto ist nicht nötig.

## Gut zu wissen

- Windows 10 oder 11 (64 Bit), kein Python nötig.
- Aufgaben, Notizen, Einstellungen und ein eigener Claude-API-Schlüssel bleiben auf dem eigenen PC (`%LOCALAPPDATA%\Desktop-Widgets`).
- Die Rezepte stammen von Chefkoch.de über eine inoffizielle Schnittstelle. Bitte nur privat nutzen.
- Dieses Repository enthält nur die fertigen Versionen zum Herunterladen.
